Protótipo · nada aqui envia mensagem de verdade

Tirei

Sorteio de amigo secreto com um link só para o grupo inteiro. À esquerda, o que o organizador faz. À direita, o que acontece no celular de cada pessoa que toca no link.

Carregando o protótipo…

A pergunta principal

Como a gente sabe quem é quem

O link que vai para o grupo é igual para todo mundo. Então, quando alguém toca nele, o app precisa descobrir quem é aquela pessoa antes de mostrar o resultado. Existem dois jeitos, e o organizador escolhe um na etapa Regras.

Grátis

Escolher o nome no link

  1. A pessoa toca no link do grupo e abre uma página do Tirei.
  2. Aparece a lista de participantes. Ela toca no próprio nome e confirma.
  3. O app trava esse nome naquele celular: guarda uma chave secreta no navegador e risca o nome da lista para todos os outros.
  4. Ela toca em “Mostrar quem eu tirei” e vê o resultado. Se abrir o link de novo no mesmo celular, cai direto no resultado.

Ponto fraco: alguém pode tocar no nome de outra pessoa de propósito. Quando a pessoa certa abrir o link, vai ver o nome riscado e avisar o organizador, que libera o nome no painel. Como o trapaceiro viu um resultado, o certo é refazer o sorteio. Em família isso quase nunca acontece, e é o jeito mais simples para todo mundo.

Plus

Confirmar pelo WhatsApp

  1. A pessoa toca no link e o WhatsApp abre uma conversa com o número oficial do Tirei, com a mensagem pronta “ENTRAR” e o código do sorteio.
  2. Ela aperta enviar. A Meta entrega essa mensagem para o nosso servidor junto com o número de quem mandou, e esse número não dá para falsificar.
  3. Se o organizador cadastrou o telefone dela, o app já sabe quem é. Se não, o robô pergunta “Quem é você?” e trava o nome naquele número.
  4. O resultado chega no privado dela, no próprio WhatsApp.

Por que é melhor: quem tem telefone cadastrado não pode ser imitado, e foi a própria pessoa que mandou a primeira mensagem. Isso cumpre a regra de aceite da Meta e coloca as respostas dentro da janela de 24 horas, que é a forma mais barata de mandar mensagem pela API. Custo: centavos por mensagem e um número oficial cadastrado na Meta.

O resultado não vai no link

Na página que você usa hoje, o resultado vai escondido dentro de cada link individual. No Tirei, o sorteio fica guardado no servidor e só é entregue para quem se identificou. Por isso um link só serve para o grupo inteiro.

Nem o organizador vê

O painel do organizador só recebe “entrou” ou “ainda não entrou”. O servidor nunca manda os pares para a tela dele, então ele também pode participar do sorteio.

Planos propostos
