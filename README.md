# Landing Page Builder

Base para criação de sites (landing pages) para pequenas empresas.

## Ideia

- **Landing page por cliente** com seções configuráveis: home/hero, sobre, serviços, galeria de fotos, localização e contato.
- **Painel administrativo (área logada)** para o dono do negócio editar textos, imagens e informações sem mexer em código.
- **Seções ativáveis/desativáveis** — cada cliente liga só o que precisa (ex.: sem galeria? desativa).
- **Página "link na bio"** estilo Linktree, também configurável pelo painel (imagem, links, etc.).
- **Mobile-first** — tudo responsivo por padrão.
